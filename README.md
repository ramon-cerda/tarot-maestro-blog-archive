# Tarot Maestro — archivo público del blog

Repositorio documental y versionado de los artículos publicados en **Tarot Maestro, el blog blanco del Tarot**.

Este repositorio forma parte de **Scotland Yard**, el centro operacional de Tarot Maestro para repositorios, versionado y trazabilidad documental.

## Regla de uso

Solo se archivan aquí materiales **ya publicados** en el blog. No se incluyen borradores, investigaciones abiertas, procedimientos internos de Baker Street ni materiales privados de trabajo.

La publicación editorial canónica es siempre la versión del artículo en el blog. GitHub conserva una copia documental y versionada para trazabilidad y reconstrucción.

Mientras el Site permanezca privado o antes de fijar el dominio público definitivo, se conserva la ruta interna canónica. Cuando exista una URL pública estable, el archivo se actualizará con la URL absoluta.
